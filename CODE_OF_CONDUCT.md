# Code of Conduct

## Our standard

Brk-Trkr contributors are expected to participate professionally, respectfully, and constructively.

Acceptable participation includes:

- discussing ideas and technical decisions on their merits;
- giving specific, actionable feedback;
- acknowledging uncertainty and correcting errors;
- respecting contributors with different backgrounds and levels of experience;
- keeping disagreements focused on the work rather than the person.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, personal attacks, or publishing another person's private information without permission.

## Scope

This code applies to repository issues, pull requests, reviews, discussions, documentation collaboration, and other project spaces managed by Brk-Trkr maintainers.

## Enforcement

Project maintainers may edit or remove contributions, comments, or participation that violate this code and may restrict participation when necessary to protect the project community.

Concerns should be raised privately with the repository maintainer rather than escalated publicly when doing so would expose sensitive information.

## Project expectations

Technical disagreement is welcome. Contributors should support claims with evidence where possible and should distinguish implemented behavior, accepted architecture, proposals, and research material clearly.
