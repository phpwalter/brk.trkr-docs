# Support

## Documentation questions

For questions about the documentation itself, open a GitHub issue in `phpwalter/brk.trkr-docs` with enough context to identify the affected document and section.

Useful issue details include:

- the document path;
- the section or heading;
- what is unclear, missing, outdated, or incorrect;
- the expected behavior or wording when known.

## Product and engineering questions

Use the repository that owns the affected implementation:

- Frontend: `phpwalter/brk.trkr-fe`
- API: `phpwalter/brk.trkr-api`
- Database: `phpwalter/brk.trkr-db`

Documentation corrections that result from those investigations should be reflected back into this repository.

## Security issues

Do not use public support issues for sensitive vulnerability reports. Follow [SECURITY.md](./SECURITY.md).
