# Security Policy

## Scope

This repository contains documentation, documentation tooling, and CI configuration for Brk-Trkr. Security issues may also relate to the Brk-Trkr frontend, API, or database repositories referenced by this documentation.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a public issue.

Report suspected vulnerabilities privately to the project maintainer through an appropriate private channel associated with the GitHub account or project.

Include, where possible:

- affected repository or component;
- affected version, branch, endpoint, or configuration;
- reproduction steps;
- expected and observed behavior;
- potential impact;
- any known mitigation.

## Documentation security issues

Examples include:

- exposed credentials, secrets, tokens, or private endpoints;
- documentation that reveals sensitive infrastructure details unintentionally;
- unsafe operational guidance;
- security-sensitive configuration examples that are incorrect or misleading.

## Handling

Security reports should be validated before public disclosure. Documentation should be updated alongside the corresponding product or infrastructure fix when the documentation itself would otherwise remain misleading.
